# MapMaker · 地图编辑器

给 IoniaCrusaderRemake 用的可视化地图编辑器。纯 Python 标准库 + 单页网页，无需安装任何依赖。界面图标统一为单色 SVG，所有确认/提示均为内置模态框（不弹浏览器原生对话框）。当前版本 **v1.4**（版本号显示在左上角标题旁）。

## 启动

- **Windows**：双击 **`start.bat`**。
- **macOS**：双击 **`start.command`**（首次若提示无法打开/无权限，在终端本目录执行一次 `chmod +x start.command`，或用 `bash start.command`）。
- 通用：在本目录运行 `python src/server.py`（macOS 用 `python3 src/server.py`）。

浏览器会自动打开 `http://127.0.0.1:8765`。关闭那个控制台/终端窗口即停止。
> 纯 Python 标准库 + 网页，跨平台；移植只需对应平台的启动脚本，`src/` 与 `config/` 不用改。

## 文件结构（代码 / 配置 / 数据 分离）

```
MapMaker/
  start.bat          Windows 启动器
  start.command      macOS / Linux 启动器
  README.md
  src/               —— 代码
    server.py          本地服务（标准库，无需 pip）
    index.html / app.js / styles.css   编辑器界面
  config/            —— 配置/输入文件
    TileType.cs        默认地形枚举（编辑器只读，不会改动；路径可在「路径」改指向游戏工程）
    EnemyUnits.json    默认敌人单位定义（路径可改指向游戏工程）
    Profession.cs      默认职业枚举（EnemyUnit 编辑器的候选值）
    Skill.cs           默认技能枚举（EnemyUnit 编辑器的候选值）
    Equipment.cs       默认装备枚举（EnemyUnit 编辑器的候选值）
    TerrainConfig.json 地形调色板 + 主题列表（编辑器自有，不随工程移动）
    MapThemes.json     关卡流程配置（阶段 / 主题 / 回合 / 地图集，路径可改指向游戏工程）
    prefs.json         用户偏好：游戏数据及枚举文件的自定义路径（自动生成/加载）
  Maps/              —— 默认地图文件夹（路径可改指向游戏工程的 Maps）
```

## 路径设置 与 刷新（顶部按钮）

- **路径**：把 **Maps 文件夹 / EnemyUnits、TileType、Profession、Skill、Equipment、MapThemes 文件** 指向你游戏工程里的实际位置，即可直接编辑/读取游戏文件。可「浏览…」弹原生选择框，或直接粘贴绝对路径；留空=用默认。设置存进 `config/prefs.json`，**下次启动自动加载**。
- **刷新**：服务端每次请求都读最新磁盘内容，但浏览器是开启时缓存的。若你用其它方式改了配置/地图文件，点刷新即可重新读取（有未保存修改会先询问）。

## 四种编辑模式（顶部切换）

- **地形**：三种笔——**画笔**（**圆形**，左键涂、右键擦为 None；**Ctrl+滚轮**或工具栏**滑条**调半径）、**矩形**（拖拽框选整块填充，右键擦除）、**填充**（整片替换相连同种地块）。
- **敌人**：每张地图可有多套预设（按权重随机）。选单位 → 点格子放置；点已有敌人可拖动移动，右键删除；不可部署的地块或玩家部署区内无法放敌人，站位非法的敌人会被标出。右侧入口可打开独立的 **EnemyUnit 配置窗口**，用于增删、复制、排序及编辑职业、技能和装备；三类枚举下拉支持搜索，匹配项置顶、完全匹配高亮，其余候选仍显示在后面，并在保存时严格按对应 `.cs` 文件校验。每个单位有**唯一的三字母缩写**（地图上标出、右侧单位列表也显示；缩写冲突时自动改用不同字母区分）。
- **部署区**：玩家的**自由形状部署区域**——左键涂格设为可部署、右键擦除（均可拖动），「清除全部」一键清空；敌人不能放置或移动到该区域。进入此模式时**高对比度显示**所有可部署格（其余变暗）。存为坐标列表 `[{x,y}]`，便于游戏反序列化、且比整张 0/1 矩阵省空间。
- **流程**：可视化编辑 `MapThemes.json`。主题按游戏阶段分段排列；折叠时显示回合数与每回合地图数，展开后可编辑主题、阶段和权重。左侧仅列出属于当前主题的地图，拖到回合中即可添加引用（双击/回车则加到最后一回合），同一地图允许重复出现，徽标实时显示它在整个流程中的引用次数。回合可增删、前后移动。**回合内每张地图都是一个 `{ mapName, weight }` 条目**：用卡片上的**数字框**单独设置权重（默认 100，回合内按权重随机抽取一张），用左侧**手柄**拖动来排序或移到其它回合（移动会保留各自的权重）。

## 主题 Theme

每个主题是一组地块；地图选定主题后**只能使用该主题的地块 +「通用」(无主题)地块**。

- 顶部「主题」按钮：新建 / **重命名** / 删除主题（存在 `config/TerrainConfig.json` 里）。
  - **重命名**：在主题列表里直接改名字后回车，会自动同步更新用到它的地图与地块。
  - **批量推断**：「主题」弹窗里的「批量推断未分类地图」会根据每张「未分类」地图实际用到的地块，自动判定并写入主题。
- 新建地图时必须选主题；顶部「主题」下拉可随时改当前地图的主题。
- 顶部「推断」按钮：按当前地图用到的地块推断主题（推断后记得保存）。
- 左侧地图列表按主题分组。
- 在「地形配置」里给每个地块设置所属主题（`(通用)` = 所有主题可用）。
- 删除主题不会改动地图文件：用到它的地图会归入「未分类」，相关地块主题清空为通用。

## 地形配置

右侧「地形配置」入口会打开独立的大型配置窗口，可视化增删改地形（数字 id / 名称 / 主题 / **可部署** / 颜色），改完点 **「保存配置」**。

- 这些修改只写入 `config/TerrainConfig.json`，**不会改动 `TileType.cs`**。
- **可部署** 勾选框：取消勾选后敌人不能放在该地块上（敌人模式下以斜纹标出该地块）。
- 你在 `TileType.cs` 里手动加了新地形后，点 **「从TileType导入」** 即可把新枚举项（含主题）并入（已有颜色不丢失），再保存。

## 撤销 / 重做

- 顶部「撤销 / 重做」按钮，或 **Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z）**；**Ctrl+S** 保存当前地图或流程。
- 作用范围是**当前地图**的编辑（地形、敌人、部署区、尺寸、主题）；切换地图会清空历史。
- 地形配置（调色板/主题）是全局配置，有独立的「保存配置」，不纳入地图撤销。

## 坐标约定

- `tiles` 为行优先数组，下标 `= y * width + x`；**x = 列，y = 行**。
- **原点在左下角**：第 0 行显示在画布最底部，y 向上递增（与游戏内方向一致）。
- 画布操作（类 PS，无滚动条，地图比视口大或小都一样）：**鼠标中键拖动**平移；**滚轮缩放**（以画布中心为锚点）；**Ctrl+滚轮**调笔刷半径；缩放滑条也可缩放。
- 地图文件以带 BOM 的 UTF-8 保存，与现有地图一致。
